☁️ Konfigurasi Cloud Database (Supabase)

Hubungkan FreshLog ke cloud database PostgreSQL Supabase untuk sinkronisasi otomatis multi-perangkat (Stok & Batch, Produk Master, Pembelian, Penjualan, dan Pengguna).

Belum Terhubung
Dapatkan dari Supabase Dashboard → Project Settings → Configuration → API → Project URL
Dapatkan dari Supabase Dashboard → Project Settings → Configuration → API → Project API keys (anon public)

🔄 Aksi Sinkronisasi Data Dua Arah

Setiap aksi penambahan, pengubahan, dan penghapusan data kini otomatis disinkronkan ke Supabase. Anda juga dapat melakukan sinkronisasi massal di bawah ini:

📤 Push: Upload Semua Data Lokal ke Cloud

Kirim seluruh data lokal (Stok & Batch, Master Produk, Pembelian, Penjualan, Pengguna) saat ini ke database Supabase.

📥 Pull: Unduh Semua Data Cloud ke Lokal

Tarik seluruh data terbaru dari database Supabase untuk memperbarui tampilan di perangkat ini.

📜 Skrip Skema Tabel Supabase (SQL)

Jalankan skrip SQL ini sekali saja di Supabase SQL Editor untuk membuat seluruh tabel yang dibutuhkan secara otomatis.
